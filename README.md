Задача: дано N-дерево. Найти ветви с максимальным числом ветвлений.

Ветвь — путь от корня до листа. Ветвление — вершина, имеющая два и более потомка.

Все структуры данных написаны вручную (готовые коллекции Java не используются).

Структура

Файл	Назначение
src/MyList.java	собственный динамический список
src/TreeNode.java	вершина N-дерева
src/NTree.java	дерево: поиск, добавление, печать
src/BranchFinder.java	рекурсивный алгоритм решения
src/Main.java	точка входа, ввод и вывод
